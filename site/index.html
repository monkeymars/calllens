See how your code actually flows

vibesequence reads your code and draws every route, command and handler as a zoomable sequence diagram: who calls whom, in what order. A map for you and your AI assistant.

How it works

Static analysis that keeps what a call graph throws away: the order of calls, and the if, loop or try around each one.

The engine in detail →
  1. ExtractParse every file; record each call in order, with its control flow.
  2. ResolveTrace self.orders.create to OrderRepo.create, through imports and inheritance.
  3. Find entry pointsRoutes, CLI commands and handlers become flows, where the User starts.
  4. ExpandWalk each flow into a tree of steps, down to the depth you choose.
  5. ZoomPick package, module, class or function as the lanes; calls inside a lane fold away.
  6. RenderA Mermaid diagram for you, and compact text with file:line for the AI.

Quickstart

Python 3.10+. Builds are incremental: a rebuild only re-parses the files that changed.
